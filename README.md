# Finanças

App financeiro do casal (Vanessa & Ana).

- **Código:** GitHub Pages (esta pasta)
- **Dados:** Firebase Firestore, separados do código. Atualizar o app não apaga nada.
- **Acesso:** chave da casa, digitada uma vez por aparelho.

`firestore.rules` guarda as regras de segurança que ficam coladas no console do Firebase.
